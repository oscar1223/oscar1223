# Hi, I'm Óscar 👋

Software developer in Seville, Spain. I build **AI agents and LLM tooling**, and help companies put them to work through [arauz.dev](https://arauz.dev).

### What I'm building

- **[Kiwi](https://github.com/oscar1223/kiwi)**: a local-first coding agent for the terminal, written in Go. It reads, edits and runs code in your project only with your permission. Install it with Homebrew or Scoop.
- **[DeepAgents](https://github.com/oscar1223/deepagents)**: a team of AI agents (planner, front, back, QA, feedback) that turns Jira Features into tasks, tests and code.
- **[LangGraph agent](https://github.com/oscar1223/langgraph-agent)**: a conversational agent with tools, memory and a modular system prompt, built on LangGraph and Mistral.
